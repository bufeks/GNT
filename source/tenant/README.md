- **奥の共用部**：1F共用廊下 9.55㎡ ／ 1F会議室 13.77㎡ ／ 1Fオフィス共用ラウンジ（FL+67〜164）／ 1F2名ブース（FL+164）
- **通り芯**：X1–X2–X3 ＝ 1,200 / 5,900 / 7,500（計14,600）。店舗区画は X2–X3 の約7,500スパン。
- **レベル差（重要）**：エントランスFL-50／店舗FL+67／ラウンジFL+67〜164／2名ブースFL+164。**段差が複数あり、車椅子動線はスロープ計画が必須**。
- **延焼ライン**あり（ファサード・開口の防火仕様に影響）。
- **上部ハッチ**（上階からの避難ハッチ）／躯体貫通は「極力低い位置で」。
- **設備系統**：給水 HI20A（外部共用部メーター単独系統）／雑排（厨房排水）VP75A／汚水 VP75A。
- **構造**：耐火被覆の大梁・スチールフレーム、間仕切壁ボード素地、ビル躯体壁／CBブロック。

> 「※計画段階の為、現場調整にて位置の変更があるものとする」注記あり。寸法は現場確定で変わり得る。

## 設計に効きそうな制約（メモ）

- **床点検口**：位置が指定されている。什器・固定物の配置で干渉回避が必要。
- **避難ハッチ（上階から）**：点線位置の直下は塞げない可能性。
- **軒ライン**：ファサード・開口・テラスの設計に影響。
- **境界線セットバック**：縁側ベンチBOX を外部に常設できる前提条件。
- 躯体へのアンカー最小限・斫り不可、天井点検口下に固定物不可、等（指針書 参照）。
